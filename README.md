# Mental Health Clinic Attendance & Revenue Analysis

### Project Overview
This project analyzes a 20-row appointment dataset for a community mental health clinic to identify patterns in patient no-shows and calculate the resulting financial loss.

### Skills Demonstrated
* **SQL:** Data querying, conditional logic (`SUM(CASE)`), and aggregation (`COUNT`).
* **Healthcare Administration:** Revenue loss calculation and operational reporting.

### Key Insights
* Found a **25% overall no-show rate**, entirely isolated to standard therapy sessions.
